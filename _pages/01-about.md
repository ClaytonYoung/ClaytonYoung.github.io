# About Me

I'm a Software Engineer focused on AI enablement and full-stack systems for scientific workflows. I design and deploy production-grade applications on AWS using Python, R, and modern web frameworks, building scalable platforms that automate reporting, standardize data workflows, and improve auditability in regulated environments.

Currently, I'm a [**Software Engineer at Genentech (gRED)**](/genentech/), where I build and deploy internal applications that enable scientists to generate, review, and iterate on preclinical study reports. I develop reusable R Shiny templates and implement report editing, validation, and change-tracking to support review workflows and auditability.

Previously, I was a Software Engineer at [**Radiata**](/radiata/), where I containerized and deployed a neuroimaging web application to AWS, transitioning it from a local prototype into a production-ready system. I set up the full infrastructure — ECS, RDS, S3, Route 53, CI/CD with GitHub Actions — and improved the frontend with React and Tailwind CSS.

Before that, I worked as an [**R Programmer at UCSF**](/UCSFMAC/), where I built a reusable dataset generation system for the Healthy Aging team. I developed an [R Shiny app](https://clayton-young.shinyapps.io/data_downloader/) and an internal [R package](https://github.com/ClaytonYoung/cRayton) that allowed researchers to efficiently generate, subset, and validate versioned datasets. I also authored documentation, led trainings, and created interactive data dictionaries to promote data transparency.

My background includes experience as a Research Coordinator at UCSF, focusing on [**decision-making in dementia and neuroethics**](https://decisionlab.ucsf.edu/). I contributed to data analyses and visualizations, resulting in eight co-authored publications. I earned my Bachelor's in Biopsychology from UC Davis, during which time I worked as a Research Assistant in two cognitive neuroscience labs studying visual working memory, attention, and language.
